تحليل متطلبات المشروع واختيار أنسب منصة استضافة مجانية

📦 ما الذي يحتويه المشروع؟ (Stack Analysis)

المشروع ضخم جداً ويحتاج موارد حقيقية — ليس مجرد موقع ستاتيك أو API بسيط:

FastAPI (Python) PostgreSQL Redis Celery Workers MLflow Server XGBoost / LightGBM / CatBoost PyTorch + Transformers SHAP / Optuna Dask Distributed React + Vite (Frontend) Nginx
⚠️ ليس مشروعاً عادياً: يشغّل 6+ containers في نفس الوقت (Postgres, Redis, Backend, Celery, MLflow, Frontend). المتطلبات الأدنى هي 2–4 GB RAM و2 vCPU على الأقل لتشغيله بشكل مستقر.

❌ لماذا Vercel غير مناسب؟

Vercel مصممة فقط للـ Frontend وServerless Functions — لا تدعم Docker, Celery, Redis, أو PostgreSQL بشكل مدمج. لو حاولت ترفع عليها سيفشل تماماً.

🥇 أفضل 3 خيارات مرتبة حسب الأنسب لمشروعك

1. Railway.app ⭐ الأفضل لـ LUMEN

يدعم docker-compose بشكل مباشر تقريباً، فيه PostgreSQL و Redis مدمجين، وعنده $5 trial مجاني يكفيك للتجربة والعرض.

  • يدعم رفع المشروع من GitHub مباشرة
  • يدعم بيئات متعددة (dev/prod)
  • Dashboard بسيط وسهل جداً
  • يمكنك رفع Backend + Celery Worker كـ services منفصلة
⚠️ الـ PyTorch + Transformers ممكن يحتاج RAM أكبر من الـ free tier — فكّر في إيقافهم مؤقتاً للـ demo.
2. Render.com ✅ خيار قوي

مشهور جداً، يدعم Docker، وعنده PostgreSQL مجاني لمدة 90 يوم. الـ free tier بيـ sleep بعد inactivity.

  • يدعم Web Services + Background Workers (Celery)
  • PostgreSQL مجاني 90 يوم
  • Redis متاح بخطط مدفوعة (أو استخدم Upstash مجاناً)
  • الـ free tier بـ 512MB RAM — قليل لـ LUMEN الكامل
3. Fly.io ✅ خيار تقني ممتاز

يدعم Docker بشكل كامل ويعطيك تحكماً أكبر. مناسب لو عندك خبرة بالـ CLI.

  • Free tier: 3 shared-cpu VMs + 3GB storage
  • Postgres و Redis متاحين
  • يحتاج flyctl CLI وإعداد يدوي أكثر

📋 خطوات الـ Deployment الموصى بها (Railway)

  1. اعمل account على Railway.app وربطه بـ GitHub
  2. أضف خدمة PostgreSQL من Railway dashboard مباشرة
  3. أضف خدمة Redis من Railway dashboard
  4. أضف New Service → GitHub Repo واختار backend/ مع Dockerfile
  5. أضف service تانية لـ Celery Worker من نفس الـ repo بـ start command مختلف
  6. الـ Frontend: ارفعه على Vercel (مجاني 100%) وعيّن VITE_API_URL لـ Railway URL
  7. عيّن Environment Variables: DATABASE_URL, REDIS_URL, SECRET_KEY
✅ نصيحة للـ Demo: عطّل PyTorch وTransformers وUltralytics من requirements.txt مؤقتاً — هيوفر عليك ~3GB RAM وبناء أسرع بكتير.

⚡ تحذير: مشكلة الـ Heavy Dependencies

PyTorch + torchvision + transformers + ultralytics + stable-baselines3 = أكتر من 5GB في Docker image. ده هيسبب:
  • Build time طويل جداً (+20 دقيقة)
  • استهلاك RAM عالي جداً حتى بدون استخدام
  • فشل على أي free tier بـ RAM أقل من 4GB
الحل: قسّم الـ requirements.txt لـ requirements-core.txt و requirements-ml-heavy.txt وابني image منفصل للـ ML workers.
